# 繁體中文歷史翻譯封存 / Historical Traditional Chinese archive

此目錄保留同步前的繁體中文翻譯、進度紀錄與輔助檔，原始內容與 Git blob 完全保留。這些文件尚未依目前上游版本更新，不應視為目前的安裝、設定或技能操作指引；封存的技能檔不放入目前的技能載入目錄。

上游曾拆分與合併多個技能目錄，部分翻譯的新位置有重名衝突。因此這次先完整封存，避免猜測對應關係或覆蓋文件。之後可逐份確認內容與新位置，再更新翻譯。

## 閱讀方式 / Navigation
